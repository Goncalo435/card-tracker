BLACKJACK TRACKER V2 — iPHONE WEB APP

This folder is ready to publish as a static HTTPS website.

Files:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

After publishing:
1. Open the HTTPS address in Safari on iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on "Open as Web App" if shown.
5. Tap Add.

After the first successful load, the service worker caches the app for offline use.
